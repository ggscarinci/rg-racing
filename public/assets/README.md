# Identidade visual RG Racing

`rg-racing-logo.png` é o arquivo original da marca utilizado no portal RG Racing, sem redesenho, filtros ou alteração de cores.

- Origem: https://brasilkart.com.br/rgracing/imagens/logo_logo_novo.png
- Página de referência: https://brasilkart.com.br/rgracing/
- Perfil indicado pelo responsável: https://www.instagram.com/kartodromo_de_goiania/
- Obtido em: 31/10/2026
- Dimensões originais: 365 × 182 pixels

A marca é exibida sobre branco em ambos os temas para preservar as letras pretas e o degradê azul. O arquivo é servido pela própria aplicação, sem depender de Instagram ou Brasil Kart durante o evento. Para TVs de resolução maior, substituir pelo original em alta resolução ou SVG fornecido pelo responsável pela identidade da marca, conservando a mesma proporção.
